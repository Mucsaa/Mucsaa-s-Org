# Áudios do Modo Foco • Polaris Agenda

Esta pasta está configurada e preparada para receber arquivos de áudio locais caso deseje substituir ou personalizar os sons sintetizados via Web Audio API:

- `natureza.mp3` ou `natureza.wav` (🌿 Som de Natureza)
- `passarinhos.mp3` ou `passarinhos.wav` (🐦 Som de Passarinhos)
- `ondas.mp3` ou `ondas.wav` (🌊 Ondas Relax)
- `ruido-branco.mp3` (🌫️ Ruído Branco)

O Polaris Agenda possui um motor sintetizador nativo via **Web Audio API** que gera os sons em tempo real, 100% offline, em loop contínuo e sem consumir internet ou falhar por links externos. Se arquivos de áudio forem adicionados nesta pasta, o sistema os detectará automaticamente!
